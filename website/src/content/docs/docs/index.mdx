Alicorn is an **experimental native GUI runtime for Odin**. You describe your UI
with ordinary Odin code; the runtime retains identity, interaction, layout,
text, and rendering products between updates.

## Start here

- [System requirements](/docs/getting-started/requirements) — set up Odin and the native toolchain.
- [Your first native app](/docs/getting-started/first-app) — run and change the starter window.
- [The retained runtime](/docs/concepts/retained-runtime) — understand what Alicorn retains and what your app owns.

## Build from a real example

The repository contains a progressive set of native examples, from a counter
and form to asynchronous lists, custom surfaces, secondary windows, themes,
controls, and retained motion.

[Browse the examples and API map](/docs/reference/api-and-examples).
